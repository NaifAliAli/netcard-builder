# محفظة جيب — NetCard Builder

## للموظفين (أيقونة فقط — بدون تيرمنال)

أرسل لهم: **`NetCard-Employees.zip`**

1. Node.js مرة واحدة من https://nodejs.org  
2. انقر **`تثبيت محفظة جيب.exe`**  
3. بعدها يستخدمون أيقونة سطح المكتب **محفظة جيب** فقط  

التفاصيل: [للموظفين.md](./للموظفين.md)

## للدعم الفني / المطور

```bat
INSTALL.bat
```
أو `npm install` ثم `npm run dev`

## الاستخدام
- **عميل واحد:** اكتب البيانات في الحقول الثلاثة (بدون Excel)
- **عدة عملاء:** استورد Excel — القالب فيه مثال: شبكه انترنت / 12345 / 777465157
- صدّر الصور باسم العميل
