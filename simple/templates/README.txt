مجلد القوالب — محفظة جيب
============================

1. انسخ صورة القالب هنا (PNG أو JPG)
   مثال: template10.png  أو  template10.jpg

2. شغّل من مجلد simple:
   powershell -ExecutionPolicy Bypass -File convert-templates.ps1

3. ارفع التحديثات إلى GitHub — يظهر القالب تلقائياً في التطبيق

تسمية مقترحة: template1.png, template2.jpg, template10.png ...
