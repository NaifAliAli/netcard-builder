# محفظة جيب — النسخة للنشر (GitHub Pages)

أداة تصميم كروت الشبكات — تعمل في المتصفح بدون تثبيت.

## 🚀 نشر على GitHub (رابط للموظفين والعملاء)

### 1. إنشاء المستودع
1. أنشئ repo جديد على GitHub
2. ارفع **محتويات مجلد `simple/`** إلى المستودع (أو ضعها في فرع `main`)

### 2. تفعيل GitHub Pages
1. **Settings** → **Pages**
2. **Source**: GitHub Actions (أو Deploy from branch → `main` → `/simple`)
3. إذا استخدمت GitHub Actions: الملف `.github/workflows/pages.yml` جاهز — يُنشر تلقائياً عند كل push

### 3. الرابط
```
https://USERNAME.github.io/REPO-NAME/
```
أرسل هذا الرابط للدعم الفني أو العملاء — لا حاجة لتثبيت أي شيء.

## ➕ إضافة قالب جديد

1. انسخ الصورة إلى `simple/templates/`  
   مثال: `template10.png`
2. شغّل من مجلد `simple`:
   ```powershell
   powershell -ExecutionPolicy Bypass -File convert-templates.ps1
   ```
3. ارفع التحديث إلى GitHub — يظهر القالب في المعرض تلقائياً

> على GitHub Pages: إذا وُجدت الصور في `templates/` تُستخدم مباشرة.  
> ملف `templates-base64.js` يعمل كنسخة احتياطية للفتح المحلي بدون خادم.

## 📋 الاستخدام

1. افتح الرابط أو `index.html`
2. يُحمَّل **template1** تلقائياً
3. أضف الليبلات (+ اسم الشبكة / + كود / + هاتف)
4. ضعها على القالب وخصّص الخط واللون
5. **تنزيل نموذج Excel** → عبّئ البيانات → **استيراد Excel** → **تصدير**
