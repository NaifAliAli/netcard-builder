الكود موجود على GitHub. تحتاج خطوة واحدة فقط لتوليد «رابط»
يفتح من أي هاتف أو جهاز قديم.


──────────────────────────────────────────────────────────────
★ الطريقة الموصى بها — Vercel (3 دقائق، مجاني)
──────────────────────────────────────────────────────────────

الخطوة 1 — افتح هذا الرابط في Chrome:

  https://vercel.com/new/clone?repository-url=https://github.com/NaifAliAli/netcard-builder

الخطوة 2 — اضغط «Continue with GitHub» وسجّل دخول GitHub

الخطوة 3 — في صفحة الإعدادات:
         • Root Directory = simple  (مهم!)
         • Framework Preset = Other
         • Build Command = اتركه فارغاً
         • Output Directory = .  (نقطة فقط)

الخطوة 4 — اضغط Deploy وانتظر دقيقتين

الخطوة 5 — سيظهر رابط مثل:
         https://netcard-builder-xxxxx.vercel.app

         أضف في آخره:  #design
         مثال:
         https://netcard-builder-xxxxx.vercel.app/#design

         ★ هذا الرابط أرسله للعملاء والدعم الفني ★
         يفتح من الهاتف · لا يحتاج تثبيت · لا يحتاج VPN


──────────────────────────────────────────────────────────────
الطريقة 2 — GitHub Pages (إذا Vercel لم يناسبك)
──────────────────────────────────────────────────────────────

1) افتح: https://github.com/NaifAliAli/netcard-builder/settings/pages

2) تحت Source اختر:  GitHub Actions
   (وليس Deploy from branch)

3) ادخل Actions وشغّل workflow «Deploy GitHub Pages» إن لم يعمل تلقائياً

4) بعد 3 دقائق الرابط:
   https://naifaliali.github.io/netcard-builder/#design

   ⚠ بعض الشبكات في السعودية تحجب github.io
   إذا لم يفتح عندك جرّب Vercel (الطريقة 1)


──────────────────────────────────────────────────────────────
ما لا تستخدمه
──────────────────────────────────────────────────────────────

  ✗ jsDelivr  — لا يشغّل التطبيق (يظهر كود HTML)
  ✗ localhost — للمطورين فقط
  ✗ 192.168.x.x — شبكة المكتب فقط
  ✗ ملف ZIP على أجهزة العملاء — إذا لا تريد تثبيتاً


──────────────────────────────────────────────────────────────
بعد النشر
──────────────────────────────────────────────────────────────

• أي تحديث ترفعه على GitHub (git push) يحدّث الموقع تلقائياً
• افتح الرابط من هاتفك للتأكد قبل إرساله للعملاء
• داخل التطبيق: زر «نسخ الرابط» ينسخ الرابط الصحيح
